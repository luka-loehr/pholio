Guide

Everything you need to publish the Lanternfly documentation, from install to the last component.

Lanternfly is an imaginary command-line tool that turns folders of notes into searchable archives. It does not exist. It is here so this demo site has something plausible to document, and so every component Pholio supports appears on at least one page.

This is a demo site. Lanternfly is fictional; the components are real.
