Writing pages

Frontmatter, headings, links and images in the Markdown subset Pholio accepts.

A page is a Markdown file with frontmatter. The title comes from the frontmatter, so the body starts at ##.

Frontmatter

Headings

Use ## for sections and ### for subsections. Headings become anchors and entries in the table of contents on the right.

A subsection

Ids are derived from the text, so this heading is reachable as #a-subsection.

A fourth level

Allowed, but rarely a good idea.

Links

Link to another page with a relative path, like Callouts and cards, or to the reference section. Broken internal links stop the build. External links such as the CommonMark spec open in a new tab.
