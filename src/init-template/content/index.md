Welcome to your new documentation site. Every page is a Markdown file in
`content/`, and `content/meta.json` sets the order of the sidebar.

![How a page travels from Markdown to the browser](/assets/images/pipeline.svg)

## Next steps

1. Edit this file while `pholio dev` is running and watch the page reload.
2. Add a page: create `content/my-page.md` and list `"my-page"` in `content/meta.json`.
3. Put images in `assets/images/` and reference them as `/assets/images/name.png`.
4. Run `pholio build` and publish the `public/` directory.
